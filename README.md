# Лабораторна робота №4

**Варіант 1** — файл даних `data/bank_managers.json` (JSON-масив).

Простий HTTP-сервер на вбудованому модулі `http`. На кожен запит сервер
асинхронно (колбеки `fs.readFile`) перечитує файл даних, фільтрує його за
параметрами рядка запиту та повертає JSON.

## Встановлення

```bash
npm install
```

## Запуск

```bash
npm start -- -i data/bank_managers.json -h 127.0.0.1 -p 3000
# або в режимі автоперезапуску
npm run dev -- -i data/bank_managers.json -h 127.0.0.1 -p 3000
```

Опції:

| Опція | Обов'язковість | Призначення |
| --- | --- | --- |
| `-i, --input <path>` | обов'язкова | шлях до файлу даних |
| `-h, --host <address>` | обов'язкова | адреса сервера |
| `-p, --port <number>` | обов'язкова | порт сервера |
| `-o, --output <path>` | необов'язкова | файл, у який записується остання відповідь |
| `--help` | — | довідка (короткий `-h` віддано під `--host`) |

## Параметри запиту (варіант 1)

| Параметр | Дія |
| --- | --- |
| `?mfo=true` | показувати код МФО (`mfo_code` ← `MFO`) |
| `?normal=true` | лише банки зі станом `1` «Нормальний» (`COD_STATE === 1`) |

Поля відповіді: `mfo_code` (за наявності прапорця), `name` ← `SHORTNAME`,
`state_code` ← `COD_STATE`.

## Приклади

```bash
curl -i "http://127.0.0.1:3000/"
curl -i "http://127.0.0.1:3000/?mfo=true"
curl -i "http://127.0.0.1:3000/?normal=true"
curl -i "http://127.0.0.1:3000/?mfo=true&normal=true"
curl -i "http://127.0.0.1:3000/unknown"        # 404
curl -i "http://127.0.0.1:3000/?min_price=10"  # 400 — невідомий параметр
```

## Обмеження роботи з файлами

Використовуються лише колбек-функції `fs`: `fs.readFile`, `fs.writeFile`,
`fs.access`. Синхронні функції (`…Sync`), `fs/promises`, `util.promisify`,
проміси, `async`/`await` не використовуються.
